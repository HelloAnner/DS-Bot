# 桌面端局域网访问

在桌面端「设置 → 通用 → 局域网访问」开启，在另一台同网段电脑打开显示的 HTTP 地址，用专用密码登录。它与「手机」和 Relay 无关，也不启动第二个 Bot 运行时。其他界面和后端配置保持不变。

- 开关仅在桌面端显示，默认关闭。每次开启只绑定用户选中的一个私有 IPv4 地址，仅接收该网卡网段上的请求。使用 TCP 8765，不更改系统防火墙，不转发端口。忘记关闭也不会在下次启动自动开启。
- 桌面端通过现有 DSH 会话鉴权配置入口。外部浏览器使用独立的随机密码和 HttpOnly 会话 cookie，不获得 DSH 管理 cookie。关闭再开启会生成新密码并注销所有浏览器。HTTP 不加密，仅限可信网络，不应转发到公网。
- 网页仅列出、读取和发送非私有 Bot 与群聊的文本消息，不开放通用 Bot API、设置、文件、原生弹窗或审批。消息使用当前桌面团队的同一聊天 Session；正常触发 Bot 的权限和任务。网页轮询更新聊天记录。
